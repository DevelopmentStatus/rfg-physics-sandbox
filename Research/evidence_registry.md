## Table source (resolved 2026-10-07)

- **Authoritative:** `build/pc/cache/misc.vpp_pc` (SHA256 `A0B00C822A9AB77CCB08C0BEEE1B36ED5BAAFFA588D160C7E9F738E99771CF5C`). Extracted with `Extractors/archive_v3.py` to `LocalData/Extracted/MiscV3/` (1684 entries). All 305 `.xtbl` files parse as well-formed XML.
- **Do not use:** `build/pc/cache/table.vpp_pc` (SHA256 `4C83D5DFEFC32D155EBB42F2ACDB581E93C7E7F8887580970EA51E88144F4148`). It carries the same 305 table names, but its directory offsets/sizes do not match where the data sits: files start 32-7600 bytes late, are cut at the directory size, and many begin with the tail of another file. Gibbed `UnpackVPP`, `RfgUtil` and `archive_v3.py` all give identical broken output, so the fault is in the archive, not the tools (only 10 of 305 parse). Why the game ships it this way is unknown; treat it as a stale duplicate. Both `table.vpp_pc` and `misc.vpp_pc` carry Gibbed's repack signature in the header.

Hashes of the files read below: melee.xtbl `73802C9EFA74378C`, weapons.xtbl `E147A5F0CEA6BE72`, tweak_table.xtbl `611E5F25240D7F59` (first 16 hex digits).
